# Hangar Fly Residence

Landing page institucional do **Condomínio Aeronáutico Hangar Fly Residence**, em Petrolina/PE.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide Icons

## Desenvolvimento

```bash
npm install
npm run dev
```

## Conteúdo editável

Textos, links, CTAs e caminhos das imagens estão em `src/content.ts`.

## Imagens

As fotografias atuais são de referência cinematográfica (aviação, arquitetura, paisagem).

Substitua os arquivos em `public/images/` pelas fotos reais do empreendimento, mantendo os nomes — ou atualize os caminhos em `src/content.ts`.

Veja `public/images/ASSETS.txt`.
